Deepgram Voice Agent POC

Talk to an end-to-end realtime voice agent.

The browser streams 24 kHz linear PCM microphone audio to this app's WebSocket proxy, which forwards it to Deepgram's Voice Agent API. Deepgram streams text events and synthesized audio back.

Idle. Add DEEPGRAM_API_KEY to .env, then run npm start.
